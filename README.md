CS 330: Computational Graphics and Visualization

Project Overview

This portfolio project is a C++ and OpenGL 3D home workout scene. I modeled a workout bench, dumbbell, water bottle, weight plate, floor, and exercise mat with basic geometric meshes. The project includes lighting, material settings, image textures for the floor and mat, camera navigation, and perspective/orthographic projection controls.

How do I approach designing software?

I start by identifying the requirements and dividing a complex scene into smaller parts. For this project, I planned the layout of exercise equipment and determined which primitive shapes could represent each object. I learned to use translations, rotations, and scaling intentionally and to think about how lighting, material choices, and camera placement affect the final result. I can apply this design process to future software projects by planning components first, using reusable functions, and checking each design choice against the requirements.

How do I approach developing programs?

I develop programs incrementally, testing one feature before adding the next. In my 3D scene, I worked with C++, OpenGL, shader settings, camera controls, and helper functions for drawing objects. Iteration was essential: I refined object placement, addressed cylinder orientation issues, and adjusted lighting when the scene appeared too bright. As the milestones progressed, I became more comfortable organizing rendering responsibilities across MainCode, ViewManager, and SceneManager instead of treating the project as one large task. The final source also adds floor and mat texture assignments and changes the mouse wheel to adjust movement speed.

How can computer science help me reach my goals?

Computational graphics connects programming with mathematical concepts such as coordinate systems, transformations, and lighting calculations. These skills will support my future coursework by strengthening my ability to reason about complex code, troubleshoot visual output, and work with interactive applications. Professionally, the project gives me experience with C++ development, modular design, debugging, and building user-controlled visual environments. These are transferable skills I can apply in software development and other technical roles.
